# Vyxia Math Companion

بص انا هرفعلك بي دي اف مادة الماث تمام  عايزك تفهرسة وتقسمة دروس تمام وتخزنها في قاعدة البيانات تمام وتستخرج كل درس وعنوانه تمام شوف ارخص واسرع نموذج عندك في lovable ai cloud تمام ده المسئول انه ياخد طلب المستخدم ويربط النموذج الي يحدده المستخدم الي احنا هنوفر 3 نماذج وهما متاحين عندك في البوابة هم gpt astra 6 و claud opus 5.5 و  claude fable 5.1 تمام ai ده يشرح اي جزئية الطالب عايزها  او يعمله كويز او نعمله انفو جرافيك بي استخدام gpt image2.5 تمام وطبعا ai هو الي هيكتب برومبت تمام وطبعا شاتات الطالب والكويزات محفوظة  و مربوطة بي حساب الجيميل بتاعه تمام بعدين الكويزات بيبقي فيها مقالي و وصح وغلط و اختر تمام  الصح وغلط والاختر والاكمل برضوا اجابتهم تكون مبعوته لاننا اصلا هنولد الاسئلة كل مرة تمام اجابتها مبعوته بحيث اننا منبعتش لي ai يصحح غير المقالي تمام دي فكرتنا تمام اسم المشروع والموقع vyxia تمام وهو اسم التيم مدرسة we luxor   تمام مطور الموقع Mohamed Atif فصل A4  تحت اشراف المستر محمد ابو زيد تمام انت كدا فهمت الفكرة كلها  المرفق ده البي دي اف بتاع المادة
